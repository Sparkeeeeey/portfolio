# portfolio

Tile-layout portfolio for Yoobin Park, live at https://sparkeeeeey.github.io/portfolio/

Vite + React + TypeScript + Tailwind CSS.

- `npm install`, then `npm run dev` to work locally
- All text (projects, experience, skills) lives in `src/data.ts`
- Images and video live in `public/img/`; put your resume at `public/resume.pdf`
- Pushing to `main` builds and deploys the site (`.github/workflows/deploy.yml`)
